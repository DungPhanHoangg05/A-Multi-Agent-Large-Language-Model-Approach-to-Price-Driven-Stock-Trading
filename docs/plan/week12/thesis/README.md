# Hồ sơ quản lý khóa luận

Nguồn dùng trên Overleaf nằm tại [thesis/](../../../../thesis/README.md).
Thư mục đó chứa `main.tex`, các chương, phần đầu, bibliography, hình sử
dụng và cấu hình biên dịch.

- [Kế hoạch viết khóa luận](plan.md) quản lý T01–T84 và các task con.
- [Sổ bằng chứng](evidence.md) giữ nguồn, giới hạn và lịch sử rà soát.
- [Dàn bài](outline.md) và [bản nháp phần đầu](frontmatter.md) hỗ trợ tra cứu.
- [Hướng dẫn build/kiểm](build-guide.md) mô tả công cụ cục bộ.
- [Source map](source-map.json) giữ hash hiện hành cùng các mốc lịch sử.
- [PDF và ZIP bàn giao](release/) dùng để xem và import bản đã kiểm.

`chapters/` giữ bản nháp Markdown, `archive/` giữ nguồn P8 và preview cũ,
`assets/` giữ nguồn hình và bằng chứng bảng. Việc biên tập bản hiện hành
thực hiện trực tiếp trong nguồn Overleaf tại `thesis/` ở gốc repository.
